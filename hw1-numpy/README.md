# ДЗ1 - NumPy

Вы аналитик небольшого онлайн-магазина. Данные уже выгружены в массивы, осталось
их посчитать.

## Что сделать

В каждом файле `taskN.py` реализуйте функции по описанию в докстринге. Сигнатуры
не меняйте, функции должны возвращать результат, а не печатать его.

| # | Файл | Тема |
|---|------|------|
| 1 | `task1.py` | Топ и ранги |
| 2 | `task2.py` | Матрица продаж и заказы |
| 3 | `task3.py` | Чистка чеков |
| 4 | `task4.py` | Недельный отчёт по магазинам |
| 5 | `task5.py` | Сегментация клиентов |
| 6 | `task6.py` | Рекомендации |
| 7 | `task7.py` | Выполним ли план: симуляция |
| 8 | `task8.py` | Почините код ассистента |
| 9* | `task9.py` | Сжатие картинки через SVD |
| 10* | `task10.py` | Симуляция воронки |

Задания 1-3 - разминка на основные операции, 4-7 - многошаговые задачи, где
одна функция собирает несколько операций в отчёт.

Задания со звёздочкой необязательные и в основной балл не входят.

Можно использовать только `numpy`. В `task8.py` код уже написан, но с ошибками:
исправьте его так, чтобы он делал то, что написано в описаниях функций.

## Как проверить себя

Из корня репозитория:

```bash
uv run python hw1-numpy/task2.py     # запустить задание на примерах из data/
uv run pytest hw1-numpy/public_tests # публичные тесты
```

Публичные тесты проверяют только самые простые случаи. Оценка выставляется по
скрытым тестам на других данных: прошедшие публичные тесты не гарантируют
полный балл.

## Оценка

Все обязательные задания весят одинаково, внутри задания балл - доля пройденных
тестов. Итог - среднее по заданиям 1-8.
