# ДЗ3 - Продуктовая аналитика

Вы аналитик приложения доставки продуктов «Корзинка». Приложение пишет лог событий: открытия,
просмотры товаров, корзина, оформление, покупки и возвраты. По нему нужно посчитать аудиторию,
воронку, удержание и деньги, а потом ответить руководителю продукта на вопросы в отчёте.

## Что сделать

Работа из двух частей.

**1. Функции (7 баллов).** В каждом файле `taskN.py` реализуйте функции по описанию в докстринге.
Сигнатуры не меняйте, функции должны возвращать результат, а не печатать его.

| # | Файл | Тема |
|---|------|------|
| 1 | `task1.py` | Загрузка лога событий |
| 2 | `task2.py` | Чистка лога и DAU |
| 3 | `task3.py` | Монетизация: ARPU, ARPPU, средний чек |
| 4 | `task4.py` | Отчёт по аудитории: DAU, WAU, MAU |
| 5 | `task5.py` | Воронка |
| 6 | `task6.py` | Когорты: удержание и накопительный LTV |
| 7 | `task7.py` | Отчёт по каналам привлечения: CAC и ROMI |

Задания 1-3 - разминка, короткие функции. Задания 4-7 - многошаговые: функция собирает отчёт
(словарь или таблицу), каждая его часть проверяется отдельно, поэтому за частично верный отчёт
тоже будут баллы.

Можно использовать `pandas` и `numpy`.

**2. Отчёт (3 балла).** Ответьте на вопросы в ноутбуке `report.ipynb`: графики и выводы. Ноутбук
можно считать своими функциями из `taskN.py` или писать код прямо в нём. Перед сдачей выполните
его целиком (Restart & Run All) и закоммитьте вместе с результатами - проверяется то, что видно в файле.

## Данные

| Файл | Что внутри | Задания |
|------|------------|---------|
| `data/events.csv` | сырая выгрузка событий, время в UTC | 1, 2 |
| `data/users.csv` | пользователи: дата регистрации, канал, платформа | 1, 2 |
| `data/clean_events.csv` | уже очищенный лог событий, московское время | 2-7, отчёт |
| `data/clean_users.csv` | пользователи для очищенного лога | 6, 7, отчёт |
| `data/marketing_spend.csv` | затраты на рекламу по неделям и каналам | 7, отчёт |

Задания независимы: очищенные файлы можно использовать, даже если задания 1-2 не получились.
Это другая выборка пользователей, поэтому сравнить её с результатом заданий 1-2 нельзя.

## Как проверить себя

Из корня репозитория:

```bash
uv run python hw3-product-analytics/task3.py     # запустить задание на примерах из data/
uv run pytest hw3-product-analytics/public_tests # публичные тесты
```

Публичные тесты проверяют только самые простые случаи. Оценка за функции выставляется по
скрытым тестам на других данных: прошедшие публичные тесты не гарантируют полный балл.

## Оценка

- **Функции - 7 баллов.** Все задания весят одинаково, внутри задания балл - доля пройденных тестов.
- **Отчёт - 3 балла.** За каждый вопрос: график подходит к вопросу, заголовок графика - вывод,
  оси подписаны; ответ верный и опирается на цифры из ваших расчётов.

## Данные синтетические

Приложение, пользователи и события выдуманы, совпадения с реальными сервисами случайны.
