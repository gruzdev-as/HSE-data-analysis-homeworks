# ДЗ2 - EDA на Pandas

Вы аналитик британского интернет-магазина подарков. Учётная система каждую ночь выгружает
заказы в CSV, а маркетинг и CRM ведут свои таблицы. Данные грязные: прежде чем считать
выручку, их нужно привести в порядок.

## Что сделать

В каждом файле `taskN.py` реализуйте функции по описанию в докстринге. Сигнатуры
не меняйте, функции должны возвращать результат, а не печатать его.

| # | Файл | Тема |
|---|------|------|
| 1 | `task1.py` | Загрузка и выборки |
| 2 | `task2.py` | Страны и отмены |
| 3 | `task3.py` | Группировки |
| 4 | `task4.py` | Чистка выгрузки |
| 5 | `task5.py` | Отчёт по странам |
| 6 | `task6.py` | Сегменты клиентов |
| 7 | `task7.py` | Динамика выручки |
| 8 | `task8.py` | Почините код ассистента |
| 9* | `task9.py` | Курс последнего рабочего дня |
| 10* | `task10.py` | Окупаемость маркетинга по неделям |

Задания 1-3 - разминка на основные операции, 4-7 - многошаговые задачи, где
одна функция собирает несколько операций в отчёт.

Задания со звёздочкой необязательные и в основной балл не входят.

Можно использовать `pandas` и `numpy`. В `task8.py` код уже написан, но с ошибками:
исправьте его так, чтобы он делал то, что написано в описаниях функций.

## Данные

| Файл | Что внутри | Задания |
|------|------------|---------|
| `data/orders.csv` | сырая выгрузка строк заказов | 1 |
| `data/orders_iso.csv` | та же выгрузка, даты в формате ГГГГ-ММ-ДД | 2, 4, 9 (готовый код запуска) |
| `data/customers.csv` | справочник клиентов (CRM) | 4, 6, 8 |
| `data/fx_rates.csv` | курсы валют на каждый день | 4 |
| `data/fx_rates_business.csv` | курсы валют только по рабочим дням | 9 |
| `data/sales.csv` | уже очищенные продажи в фунтах | 3, 5-8, 10 |
| `data/marketing.json` | затраты на маркетинг по неделям | 10 |

Задания независимы: каждое читает свои данные и не использует функции из других заданий.

## Как проверить себя

Из корня репозитория:

```bash
uv run python hw2-pandas-eda/task2.py     # запустить задание на примерах из data/
uv run pytest hw2-pandas-eda/public_tests # публичные тесты
```

Публичные тесты проверяют только самые простые случаи. Оценка выставляется по
скрытым тестам на других данных: прошедшие публичные тесты не гарантируют
полный балл.

## Оценка

Все обязательные задания весят одинаково, внутри задания балл - доля пройденных
тестов. Итог - среднее по заданиям 1-8.

## Источник данных

Заказы основаны на датасете Online Retail II (Chen, D. (2012). UCI Machine Learning
Repository, https://doi.org/10.24432/C5CG6D, лицензия CC BY 4.0): взята выборка, столбцы
переименованы, добавлены валюты, справочник клиентов, курсы и затраты на маркетинг.
