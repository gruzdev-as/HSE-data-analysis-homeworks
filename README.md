# Домашние задания - курс «Python для анализа данных»

Репозиторий с домашними заданиями курса «Python для анализа данных» для
магистров программы «ИИ в маркетинге и управлении продуктом» (ВШЭ).

## Структура

- [hw1-numpy/](hw1-numpy/) - ДЗ1: NumPy, линейная алгебра на данных, симуляции.
- [hw2-pandas-eda/](hw2-pandas-eda/) - ДЗ2: очистка, агрегации и объединения в Pandas.
- [hw3-product-analytics/](hw3-product-analytics/) - ДЗ3: продуктовая аналитика по event-логу.

Каждая папка с домашкой содержит свой README с условием задания.

## Сдача и проверка

1. Создайте свой репозиторий из этого шаблона (Use this template) в организации курса
   и назовите его `da-<ваш логин на GitHub>`, например `da-ivanov`.
2. Решайте задания в `taskN.py` и отправляйте их коммитами (push) в свой репозиторий.
3. Автопроверка проходит несколько раз в день: она берёт последний push, запускает тесты
   и пишет результат в issue «📋 Результаты автопроверки» в вашем репозитории. Ничего
   запускать вручную не нужно.

Оценка выставляется по скрытым тестам на других данных: в результатах видно, сколько тестов
прошло, но не какие именно. Публичные тесты в `public_tests/` проверяют только самые простые
случаи - запускайте их, чтобы убедиться, что функции хотя бы работают.

В зачёт идёт последний push до дедлайна. Если после дедлайна вы что-то исправили, будет
засчитана лучшая из оценок: в срок или с опозданием со штрафом (см. правила курса).

## Окружение

uv sync
uv run pytest hw1-numpy/public_tests
